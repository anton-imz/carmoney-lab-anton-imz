Режим Ask создан для консультаций и генерации идей без прямого вмешательства в проект, тогда как режим Code запускает автономного AI-агента, который может самостоятельно писать код, создавать файлы и выполнять цепочки задач.

code - писать, оптимизировать, рефакторить код
ask - искать информацию, отвечать на вопросы
plan - разбивать большие задачи на шаги
debug - искать ошибки, предлагать исправления
